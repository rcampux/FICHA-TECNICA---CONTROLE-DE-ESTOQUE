# Navegação mobile

No rodapé de telas abaixo de 768 px, a ordem visual é Virtual, Físico, Ficha, Receitas e Cozinha. Ficha é a ação central: círculo elevado vermelho, texto branco, foco de teclado e indicação de seleção. O clique mantém a navegação existente para a ficha, sem limpar seu conteúdo.

Tablet e desktop mantêm a navegação lateral existente. A implementação é somente CSS, sem novas funções.

Próximo passo: conferir a navegação entre Ficha e Receitas no celular.
